## 📝 Description / 상세 설명

## 💻 Usage / 사용법

### SwiftUI

```swift
// SwiftUI 사용 예시
button.animationKit(.pop, trigger: isLiked)
```

### UIKit

```swift
// UIKit 사용 예시
button.animationKitPop()
```
