# Fade Animation (Basic)

> 뷰의 투명도(Opacity)를 부드럽게 조절하여 나타나거나 사라지는 가장 기본적인 애니메이션입니다.

## 📝 Description / 상세 설명

- **특징**: 시스템 자원(GPU/CPU)을 거의 소모하지 않습니다.
- **용도**: 팝업 등장, 화면 전환, 데이터 로딩 후 콘텐츠 노출.

## 💻 Usage / 사용법

### SwiftUI

```swift
// SwiftUI 사용 예시
view.animationKit(.fade, duration: 0.3)
```

### UIKit

```swift
// UIKit 사용 예시
view.animationKit(.fade, duration: 0.3)
```
